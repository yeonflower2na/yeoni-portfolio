## 실험 주제

노션에 쌓인 팀 업무기록과 회의록을 헤르메스 에이전트가 읽고, Mattermost에서 요청하면 현재 업무를 상태별로 자동 정리하도록 구성했습니다.

이미지 작업이 필요한 경우에는 Higgsfield를 연결해 간단한 이미지 생성과 기존 이미지 편집까지 Mattermost에서 요청할 수 있도록 만들었습니다.

## 가설

노션에 이미 작성된 업무기록을 에이전트가 직접 읽고 분류한다면, 매번 노션 페이지를 하나씩 열어 업무 현황을 확인하는 시간을 줄일 수 있을 것이라고 생각했습니다.

또한 평소 사용하는 Mattermost를 실행 창구로 활용하면, 여러 도구를 직접 오가지 않고 한곳에서 업무 조회와 이미지 작업을 처리할 수 있을 것이라고 가정했습니다.

## 실행한 것

헤르메스 에이전트에 다음 도구를 연결했습니다.

- **Mattermost**: 명령 입력 및 결과 확인
- **Notion**: 팀 업무기록과 회의록 조회
- **Codex**: 업무 내용 분석 및 요약
- **GitHub**: 반복해서 사용할 스킬과 업무 정리 규칙 저장
- **Higgsfield**: 이미지 생성 및 편집

Mattermost에서 업무 정리를 요청하면 노션의 기록을 조회해 다음 네 가지 상태로 분류하도록 했습니다.

- 완료 업무
- 진행 중 업무
- 시작 전 업무
- 보류 업무

전체 흐름은 다음과 같습니다.

**[업무관리]**

```
Mattermost에서 요청
→ Hermes Agent 실행
→ Notion 업무기록과 회의록 조회
→ GitHub에 저장된 정리 규칙 적용
→ Codex가 업무를 분석하고 상태별로 분류
→ Mattermost에 결과 전달
→ Notion 결과 반영 (업무 추가 및 상태 변경)
```

**[이미지 작업]**

```
Mattermost에서 이미지 생성 또는 수정 요청
→ Hermes Agent가 요청 내용 정리
→ Higgsfield에서 이미지 생성 또는 편집
→ Mattermost에 결과 확인
```

## 결과

Mattermost에서 "이번 주 팀 업무를 정리해 줘"라고 요청하면, 에이전트가 노션의 업무기록을 확인하고 다음과 같이 상태별로 정리해 전달했습니다.

- 완료 업무
- 진행 중 업무
- 시작 전 업무
- 보류 업무

기존에는 노션 페이지를 직접 열어 업무 상태를 확인해야 했지만, 자동화 이후에는 Mattermost에서 한 번 요청하는 것만으로 현재 업무 현황을 빠르게 파악할 수 있었습니다.

이미지 작업도 함께 테스트했습니다. Mattermost에서 요청한 내용을 바탕으로 Higgsfield에서 간단한 이미지를 생성하고, 기존 이미지의 색감이나 일부 요소를 수정하는 기능이 정상적으로 동작하는 것을 확인했습니다.

이미지 생성과 편집은 초안 제작과 반복 수정에 활용하고, 최종 결과의 사용 여부와 완성도는 디자이너가 직접 판단하도록 했습니다.

## 배운 점

### 1. 업무 자동화

Mattermost에서 노션의 업무기록을 조회해 팀원끼리 현재 업무 상황을 더 빠르게 파악하고 관리할 수 있었습니다. 각 도구를 하나의 흐름으로 연결하니 실제 업무에서 더 편하게 활용할 수 있었습니다.

### 2. 이미지 작업

간단한 이미지 생성과 편집 기능이 정상적으로 동작하는 것을 확인했습니다. 다만 전문적인 디자인 작업보다는 빠르게 처리해야 하는 간단한 이미지 업무나, 이미지 제작 도구에 익숙하지 않은 다른 부서에서 활용하기에 더 적합해 보였습니다.

## 실험 주제

Mattermost에서 명함을 요청하면 노션 데이터베이스에 자동으로 추가·수정되고, 그 내용이 명함 웹사이트에 그대로 반영되도록 구성했습니다.

명함은 종이 대신 웹으로 만들었습니다. 3D로 뒤집어 볼 수 있고, 연락처를 저장하거나 공유할 수 있습니다.

## 가설

명함은 만들 때보다 바뀔 때 손이 더 많이 갑니다. 부서 이동이나 직급 변경이 있으면 노션을 고치고, 디자인 파일을 고치고, 다시 전달하는 과정을 매번 반복해야 했습니다.

요청 창구를 Mattermost 하나로 두고 노션과 웹사이트를 연결하면, 요청부터 반영까지 한 번에 끝낼 수 있을 것이라고 봤습니다.

## 실행한 것

**연결한 도구**

- Mattermost: 명함 제작과 수정 요청
- Notion: 임직원 명함 정보 데이터베이스
- 명함 웹사이트: 3D 명함 열람, 연락처 저장과 공유

**전체 흐름**

```
Mattermost에서 명함 요청
→ Hermes Agent 실행
→ Notion 데이터베이스에 추가 또는 수정
→ 명함 웹사이트에 반영
→ Mattermost에 결과 전달
```

**웹사이트에 만든 기능**

- 3D 명함: 눌러서 뒤집고, 마우스를 올리면 확대됩니다
- 연락처 저장과 공유: QR 코드와 전화, 문자, 메일 바로가기
- 한국어와 영어 전환
- 연락처 수정과 삭제
- 마이페이지: 받은 명함을 사진으로 찍어 보관하고 관리

## 결과

Mattermost에서 명함 제작을 요청하면 노션에 항목이 추가되고, 웹사이트 목록에도 바로 나타났습니다. 정보를 고칠 때도 같은 경로로 처리했습니다.

관리자 화면에서는 팀별로 명함을 확인하고, 연락처 수정과 QR 다운로드를 한곳에서 처리할 수 있게 했습니다.

받은 명함은 사진으로 찍어 마이페이지에 모아둘 수 있어 종이 명함을 따로 보관하지 않아도 됩니다.

## 배운 점

만드는 것보다 고치는 것을 줄이는 쪽이 효과가 컸습니다. 명함 하나를 수정하려고 여러 파일과 사람을 거치던 과정이 요청 한 번으로 정리됐습니다.

디자인은 사람이 정하고, 반복되는 데이터 입력과 반영은 자동으로 넘기는 구조가 실제 업무에 맞았습니다.
